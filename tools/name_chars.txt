# 為什麼要這份檔？直接從筆劃反查會列出屍、癌、屁、賤這類字。
# 筆劃是資料問題，「這個字能不能拿來取名」是編輯判斷，所以分開。
#
# 格式：一行一組，# 開頭是註解，只有 CJK 漢字會被讀取（空白、標點都會忽略）。
# 筆劃不用在這裡標 —— build_strokes.py 會自己去康熙筆劃表查並分組，
# 手寫筆劃一定會出錯。
#
# 要加字直接加在對應主題後面；要刪就刪掉。改完跑：
#   python tools/build_strokes.py
